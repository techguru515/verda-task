# Summary

Three Verda VMs run RKE2 v1.36.5+rke2r1 and Cilium 1.20.2 with Hubble and kube-proxy replacement. Host ufw is the public boundary: SSH from one admin address, cluster mesh and pod/service CIDRs allowed, API port 6443 listening and not publicly allowed. `team-a` and `team-b` are Pod Security restricted. Argo CD syncs namespaces, network policy, Kyverno, RBAC, and both apps from a git daemon on the control node. All six Applications were Synced and Healthy, and the team-b web Deployment carries the GitOps label from commit `b989c57`.

The controls were executed and the output was kept. The team-b client got HTTP 200 from its own web Service. The team-a client timed out to that Service and to 1.1.1.1, and Hubble recorded both as policy drops. Kyverno denied `:latest`, a missing tag, and `docker.io/library/busybox`. Pod Security denied a privileged pod. The team-a ServiceAccount cannot read the team-b secret. Trivy found 31 criticals on `nginx:1.14.2` and zero criticals on the unprivileged nginx used by the app. Prometheus alert `CriticalVulnerabilityDetected` was firing (value 35, since 16:53Z). Grafana’s health endpoint and the vulnerability dashboard API both responded. `kyverno test` with CLI 1.19.2 passed 7 tests. The CI workflow pins that CLI, fails Trivy config findings at CRITICAL, and fails a fixed critical in an image. It has not run on GitHub.

Tradeoffs. The `for` window is 1 minute so the alert could fire in this session. `ClusterPolicy` is deprecated in Kyverno 1.19 and still enforces. The curl image is allow-listed and still has CVE-2026-31789; OpenSSL rates that Low and 32-bit only, while Trivy counts it critical, so the alert is wider than the bug on these amd64 nodes. Scanning does not remove the pod. The git remote is on the control node because there is no GitHub remote yet. One control plane is a single failure domain. team-b web requires a client certificate on port 8443 (HTTP 200 with the certificate, HTTP 400 without it). Images from the lab registry must carry a cosign signature: the signed nginx pod became Ready, and the unsigned curl image was denied with `no signatures found`.

Shut the three VMs down when you finish. They cost about $0.21 per hour. The ids and the tunnel steps are in `docs/access.md`.
